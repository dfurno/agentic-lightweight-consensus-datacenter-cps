# Smart Cities Round 1 Evidence

These packages are the authoritative curated evidence for the revised manuscript. They preserve the run reports, manifests, provenance, hashes, aggregate outputs, and adverse outcomes used in the paper-facing tables and statements.

The packages do not contain reviewer reports or response letters. Absolute server paths in provenance files record the original execution environment and should be mapped to the local repository when replaying.

No new LLM inference or GPU campaign was used for these Round 1 additions. The thermal studies use a declared illustrative software model and simulated actuator; they do not establish physical thermal or energy performance.
